# Private repository contents

This repository is the development source for Equilibria / Open Venture Framework.
It is private; public-release gates remain in [TODO](../TODO.md).

## Versioned

- Python source, package configuration, tests, financial fixtures and runnable examples.
- The mathematical README, API quickstart, calculation semantics, model limits and
  fixture derivations.
- Roadmaps, TODO, research reports, review notes and the CSV/XLSX knowledge base.
- Launch preparation and keyword research, including the 12 raw suggestion responses
  and the provider's tool schemas. Search-volume metrics were unavailable.
- The README figure, its underlying data, validation results and reproduction script.
- License, citation, contribution guidance, issue templates and CI configuration.
- Portable project instructions for coding assistants and the project-specific skill.
  The Claude skill link is relative to the repository.

## Local only

- Virtual environments, caches, coverage output and built wheels/source archives.
- The duplicate workbook in `out/` and Excel lock files.
- Environment files, private keys and credential files.
- Local Orca completion records and MCP connection/initialization diagnostics.

The root CSV and XLSX are retained as the research deliverable; generated package
archives can be rebuilt from source. Historical reports and launch drafts retain
their stated dates and review status. The root [README](../README.md) and current
module documentation describe the working checkout; an archived document does not
establish that a feature is implemented or that an experimental claim is verified.
